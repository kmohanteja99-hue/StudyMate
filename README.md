# 📚 StudyMate — Smart Study Dashboard

StudyMate is a student-friendly study dashboard built using HTML, CSS, and JavaScript. It helps students organize tasks, manage study time, and track their progress.

## ✨ Features

- 📅 Interactive study calendar
- ✅ Add, manage, and complete study tasks
- ⏱️ Focus timer for study sessions
- 📊 Study analytics and progress tracking
- 📝 Notes creation and management
- 🤖 Offline study helper with built-in topic explanations
- 🔔 Sound and browser notification options
- 🌙 Dark and light themes
- 💾 Save tasks and notes using browser local storage
- 📱 Responsive design for mobile and desktop
- 📤 Export study data for backup

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
- Browser Notifications API

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension, or open it directly in a browser.
4. Start adding your study tasks and notes.

## 🤖 Offline Study Helper

The built-in study helper provides explanations for selected topics without requiring an API key or internet connection. Its answers are limited to the topics included in its built-in knowledge library; it is not a full generative AI model.

## 💾 Data Storage

Study tasks, notes, and preferences are stored in your browser. Clearing browser storage may delete saved data, so use the app's export feature to create backups.
